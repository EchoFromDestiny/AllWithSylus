# Song for Someone

发布日期：2025-10-20

---

	(一点结婚小甜饼)
	这是我和秦彻认识的第三年。虽然我们的感情已经很深，但他拿出戒指在我面前单膝跪下的那一瞬，我的眼泪还是不受控制地流了出来。
	或许是因为我从没想过他会愿意娶我。他那么桀骜不驯的一个人，此时此刻却抬眼看着我，眼波中流转着光。
	谁知道呢，三年前认识，还是因为打打杀杀的事。

	“你会记得吧，亲爱的。”秦彻搂着我，窗外是一弦新月，柔柔的月辉虽不及满月时灿烂，却淡淡的别有一番情意，“你会记得第一次要你共鸣，我强迫你吗？”
	“我倒希望忘记呢。”我笑了，抬手刮了刮他的鼻梁。秦彻也笑了，放在我手背的那只大手又搂紧了点。“现在的秦先生，可是比刚认识那会温柔多了。”
	“那……婚礼要来了，你紧张吗？”
	“其实有点呢。”我往他怀里缩了缩，秦彻似乎是明白我的意思，将他穿的毛衣外套扯了扯，裹住我。“别紧张，我一直都在。”
	“秦彻，我不敢想结婚的时候是你先紧张到想跑还是我。”我抬头看他，那双曾经冰冷的红瞳如今温柔的如同床头的小夜灯，在月光的映照下闪着柔和的光。
	“你可不能跑，你跑了我就紧张了。”秦彻的嘴角微微上扬，眼角都是难掩的笑意。
	“那我不跑，但是你不能怯场。”
	“和你结婚，没有怯场的理由。”

	我想起那次，我托他照顾生病的小鸽子，看似凶神恶煞的秦彻却将小鸽子照顾的很好。
	我想起那次，他不为任何理由约我出来，那是我第一次被人背着看高处的风景。
	我想起那次，我们在海边冲浪，他迎着海风亲吻我的唇……
	一回忆，才发现原来我们已经一起度过了那么多个日日夜夜。这次我没有早睡，明天就要结婚了，我想陪着他守过今晚。
	“你还是去睡吧，明天结婚顶着两个黑眼圈怎么看。”
	“不要。我想陪你守着。”
	秦彻的手将我拢进他的怀里。“那就靠近点，别着凉了。我可不希望你明早穿上婚纱就先打两个喷嚏。”
	我把脑袋靠到他的胸口。沉稳的心跳声有力而沉静，他的双手环着我，轻轻拍着我的背。我闭上眼，听着他轻轻哼我们选好的要在婚礼上放的那首《Song for Someone》，略微有些低沉的声音别有一番味道。
	“And there is a light,
		don't let it go out
		And this is a song
	 	a song for someone……”
	我听着他的声音，多了三年前初见他时没有的温柔，比以前更轻，更柔和。
	“秦彻。”
	“嗯？”他停下来，低头看向我。
	“比以前刚认识你那会唱的好多了。”
	“好歹练了那么久。”他笑了。
	“其实你一直都唱的挺好的。”
	“你要是三年前这么说我会当真。”秦彻捏了捏我的脸，“但是现在……我就只能当成我亲爱的老婆大人为了不打击我的积极性而睁眼说瞎话了。”
	我有点想给他一拳，于是伸出手在他胸口轻轻锤了一下。“我可没睁眼说瞎话。”
	“也就你敢这么捶我。”
	“怎么了，难道犯了错还不让我打了？”
	“随老婆大人处置。”秦彻低下头，在我额前落下一个吻。
	“那就不许你说我睁眼说瞎话。”
	“左一个不行，右一个不许，你好凶啊。”
	我笑了。“又夹嗓子，秦彻你不许学我说话。”
	秦彻也笑了，伸手轻轻弹了一下我的脑门。“就学。”
	听秦彻唱了有半个小时，我迷迷糊糊的还是睡着了。梦里他穿着西服，如同我无数次想象的那样，拿出戒指，单膝下跪，抬头与我微笑对视。
	明天，这一切就要成真了。

	“起来了，小懒猫。”我是被秦彻抱着起身时颠醒的，“换上婚纱，今天小狸花就要嫁给我了。”秦彻手里拿着西服，转身就进了次卧，同时指指主卧的门，“婚纱礼服都放床上了，去换吧。”
	我进了主卧，尽自己所能以最快的速度穿上婚纱。我出门的时候秦彻已经拿着手捧花在等我了。“小猫今天真的很美。”他弓腰，向我伸出手，“请狸花大王跟我来。”
	我挽住秦彻的手，走出房门。薛明薛影已经在门口停好了车，秦彻拉着我坐到后座，车子随即启动，飞驰向我们将要举办婚礼的地方。
	秦彻为了我曾经提过的“想要草坪婚礼”，在临空市市郊租了一片最好的草坪。我一下车，迎接我的便是陶桃和楠队。“新娘子和新郎到啦！”陶桃兴奋的大喊，“快出来接人啊！”
	猎人协会的朋友们都来了，他们在这次婚礼中就是我的娘家人。楠队看着陶桃围着我转圈圈，转头对秦彻说：“秦彻，你不能亏待她，不然我们娘家的人可不答应。”
	“不可能亏待她。”秦彻绅士地鞠了一弓，“楠队，待会还得请你把她交给我。”
	楠队轻轻点了点头，“希望你能让她幸福。”
	“我会的。”秦彻轻声说。
	这时音乐响起，时间到了。秦彻大步走向主舞台，我和楠队则站在花海长廊的另一端，等着婚礼正式开始。
	是《Song for Someone》。
	我以为秦彻只是说着玩，没想到他真的选了这首。吉他声似乎拨动着每一个人的心弦，主唱的声音似乎在倾诉一个人能有的最深沉最真诚的爱。
	楠队牵着我的手，走向舞台的那一端，走向我将要踏入的新的生活。
	每一步，我都在向他靠近一分，如同三年来的感情，时间每流逝一分，我们彼此间的情感便更深一分。他站在那一端，眼底的笑意温柔明媚。
	楠队轻轻抬起我的手，我这才惊觉我们已经走到了秦彻面前。
	她把我的手放到秦彻温热的手掌间，轻轻的对着秦彻点了点头。
	“秦彻先生，无论富贵还是困苦，无论生老或是病死，你都愿意与你的妻子不离不弃吗？”
	“我愿意。”
	他眼里的光那么亮，如同我目光所及的整片星河。
	那一瞬，他变戏法般托出一个小小的首饰盒，一打开，这次再不是空的，里面躺着他为我定制的婚戒。
	秦彻后退一步，单膝下跪，抬起头，发丝在风中轻轻摆动。
	“你愿意嫁给我吗，亲爱的？”
	“我愿意。”
	他为我戴上那枚镶着红宝石的婚戒，但宝石的光泽竟不及他那双眼万分之一。
	他站起身，单手搂住我的腰，抱着我转起了圈，裙摆飞扬，一阵风起，花树下起了花瓣雨，而我们在这雨中，用最甜蜜的微笑回应对方的爱意。
	“You got a face not spoiled by beauty
		I have some scars from where I've been
		You've got eyes that can see right through me
		You're not afraid of anything they've seen
		I was told that I would feel nothing the first time
		I don't know how these cuts heal
		But in you I found a rhyme
		If there is a light you can't always see
		And there is a world we can't always be
		If there is a dark that we shouldn't doubt
		And there is a light, don't let it go out
		And this is a song, song for someone
		This is a song, song for someone……”
	我们会在彼此的爱之中找到属于我们的共鸣，会在光明之中拥有一个仅仅属于我们彼此的世界，会在真正的深情中成为彼此最不可分割的那一部分。
	花雨随风而起，他将我举起，我们的笑在风中飞扬。
	我们，本就一体。
